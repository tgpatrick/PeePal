PeePal
========================

![License](https://img.shields.io/badge/license-AGPL-lightgrey.svg)
![iOS](https://img.shields.io/badge/platform-ios-lightgrey.svg)

PeePal is a simple Swift/SwiftUI app implementing the Refuge Restrooms API. It was built to mimic the functionality of the now-defunct [official Refuge Restrooms iOS app](https://github.com/RefugeRestrooms/refugerestrooms-ios), but with a modern tech stack and design.

## API

PeePal uses the [Refuge Restrooms API](http://www.refugerestrooms.org/api/docs/).

## Installing

PeePal can be installed on iOS/iPadOS 17.4+ or on macOS 14.4+ on a Mac with Apple Silicon. It can be found on the <a href="https://apps.apple.com/us/app/peepal-refuge/id1540530097">App Store</a>.

PeePal also has a public beta version. You can install it on those same operating systems through <a href="https://testflight.apple.com/join/pyJft4eT">TestFlight</a>.
